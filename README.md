# 🚨 Operation: Lost Signal
### Adaptive Rescue Intelligence System

## 📌 About the Project
Operation: Lost Signal is a web-based rescue dashboard prototype designed to help rescue teams monitor missing trekkers, assess risk levels, and organize critical information during emergencies.

It combines trekker status, location confidence, risk assessment, and offline-update simulation in one interface to support faster, better-informed rescue decisions.

## ✨ Key Features
- **Six-Trekker Dashboard:** Monitor six sample trekker profiles in one place.
- **Risk Assessment:** Calculate illustrative risk scores using injury, battery, signal, weather, terrain, and location freshness.
- **Location Confidence:** Identify potentially outdated or uncertain location information.
- **Mission Lab:** Simulate emergency scenarios and observe changes in risk levels.
- **Offline Simulation:** Queue demo updates and simulate synchronization when connectivity returns.
- **Rescue Event Log:** Review recorded events and synchronization activity.
- **ShoeTrace Concept:** Demonstrate a wearable tracker interface for phone-failure scenarios.

## 🚀 How to Run
1. Download or clone this repository.
2. Open the project in VS Code.
3. Run `index.html` using the Live Server extension.
4. Explore the dashboard and its simulation features.

## 💡 Innovation
The project combines explainable risk scoring, location-confidence indicators, offline workflow simulation, and a wearable tracking concept to explore a more organized approach to rescue coordination.

## ⚠️ Limitations
This is a hackathon prototype using sample data. GPS tracking, wearable hardware, emergency communication, and offline synchronization are simulated and are not connected to real rescue services.
